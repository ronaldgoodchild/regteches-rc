Title: I built a free all-in-one SSH/SFTP/RDP manager for Windows after getting tired of PuTTY + WinSCP + mstsc + a spreadsheet

Body: Every server I own lived in a different tool. So I wrote RC: one window with a server list on the left and tabs on the right. Click a server, then click SSH (terminal tab), Files (WinSCP-style two-pane manager with drag and drop and folder sync), Remote Desktop, Web, PowerShell, Ping or a service check. There is also a bulk SSH-key installer (generates an ed25519 key and installs it on every box you tick), SSH tunnels, saved commands you can run on many servers at once, Ctrl+K quick search, and colour themes. Python/Tkinter + paramiko, single EXE, source included. Feedback welcome.
